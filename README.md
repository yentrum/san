# Sàn Yến Trùm

Trang web giới thiệu **Sàn Yến Trùm – Ứng dụng AI cho Seller & Affiliate**.

## Cấu trúc

```
index.html      Trang chính (HTML, CSS, JS viết sẵn trong một file)
img/            Ảnh minh hoạ trong trang
logo.png        Logo
logo-wide.png   Logo ngang
favicon.png     Biểu tượng tab trình duyệt
yen-trum.jpg    Ảnh chân dung
```

## Xem trang

Không cần cài đặt hay build. Mở file `index.html` bằng trình duyệt là chạy.
Font Be Vietnam Pro tải từ Google Fonts, cần có mạng để hiện đúng font.

## Đưa lên mạng bằng GitHub Pages

1. Vào **Settings → Pages** của repo.
2. Ở mục **Source**, chọn **Deploy from a branch**.
3. Chọn nhánh `main`, thư mục `/ (root)`, bấm **Save**.
4. Đợi 1–2 phút, link web sẽ hiện ở đầu trang Pages.

## Chỉnh sửa

- Đổi chữ, link: sửa trực tiếp trong `index.html`.
- Đổi ảnh: thay file trong `img/`, giữ nguyên tên file.

Thư mục `stickman-editor/` chứa công cụ dựng video người que tự động chạy trên trình duyệt. Xem hướng dẫn trong `stickman-editor/README.md`.
